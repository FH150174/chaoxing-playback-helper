# 学习通视频与 PPT 连播助手

适用于 Chrome + Tampermonkey 的用户脚本。它依次处理课程中可识别的未完成视频、音频与 PPT/文档任务点。检测到章节测验或课后习题时会跳过，继续查找下一任务卡或章节；**测验不会被作答或标记为完成**。

[安装或更新脚本](https://raw.githubusercontent.com/FH150174/chaoxing-playback-helper/main/chaoxing-playback.user.js) · [查看源码](chaoxing-playback.user.js)

## 安装与使用

1. 在 Chrome 中安装 Tampermonkey，点击上方安装链接并按提示安装或更新。如果浏览器只显示源码，可复制全部内容到 Tampermonkey 的新建脚本中。
2. 如果曾手动安装旧版本，停用旧脚本，避免两个版本同时运行。
3. 打开学习通电脑端课程学习页，点击右下角“开始连播”。默认使用 2×、静音和后台播放兼容。
4. 播放器不允许倍速时，当前视频自动退回 1×。视频和 PPT 都以网站实际显示的任务完成标记为准。需要停止时点击“停止连播”。

播放设置保存在当前浏览器标签页的课程会话中。升级后，脚本会清除旧版保存在 Tampermonkey 中的 DeepSeek API Key、模型设置和当前课程的做题会话记录；新版没有答题界面，也不会向 DeepSeek 发送请求。

## 测验跳过规则

- 如果当前任务卡同时有测验和视频/PPT，脚本继续处理视频/PPT。
- 如果任务卡只剩测验，脚本转到下一张任务卡或下一节尚未检查过的章节。本轮已检查过的章节不会因测验仍显示“未完成”而被反复打开。
- 测验保持未完成，仍需手动处理。若课程设置了“完成测验后才能解锁下一节”，脚本无法访问被锁定的章节。

## 工作范围与限制

- PPT 按可访问阅读区域的可见高度逐步下滑；到达底部后仍未显示完成标记时，最多等待 60 秒。
- 如果网站明确禁止倍速，或播放器在倍速下暂停、恢复原速或拒绝播放，当前视频退回 1×。如果课程只在服务端校验观看时长，网页没有可见限制，可手动选 1×。
- 后台兼容只处理网页的失焦与可见性回调；Chrome 可能节流或冻结最小化窗口，因此无法保证最小化后持续运行。
- 验证码、跨域且不可访问的播放器，以及无法识别的非视频/PPT任务点，需要手动处理。脚本不会伪造任务完成标记或发送进度请求。

## 本地开发与验证

    npm ci
    npm test
    npm run check

脚本没有运行依赖；jsdom 仅用于模拟课程页面并测试任务切换、视频、PPT 与测验跳过。项目使用 [MIT 许可证](LICENSE)。
