# 学习通视频与 PPT 连播助手

适用于 Chrome + Tampermonkey 的用户脚本。它在学习通电脑端依次处理当前课程中可识别的未完成视频、音频、PPT/文档和章节习题任务点：视频可选择 1×、1.5× 或 2×，PPT 在可访问的阅读区域内逐屏下滑，章节习题可使用用户自己的 DeepSeek API 解答。脚本只在页面显示任务完成标记后切换到下一项。

[安装或更新脚本](https://raw.githubusercontent.com/FH150174/chaoxing-playback-helper/main/chaoxing-playback.user.js) · [查看源码](chaoxing-playback.user.js)

## 安装与使用

1. 在 Chrome 中安装 Tampermonkey。
2. 点击上方“安装或更新脚本”，按 Tampermonkey 提示安装。如果浏览器只显示源码，可复制全部内容并粘贴到 Tampermonkey 的新建脚本中。
3. 如果之前手动安装过旧版，先停用旧脚本，避免两个版本同时运行；确认新版正常后可删除旧版。
4. 刷新学习通电脑端课程学习页。需要处理章节习题时，先点击右下角“设置 DeepSeek Key”，在浏览器中输入自己的 API Key，并选择习题模型；不要把密钥发到聊天或提交到 GitHub。更新后 Tampermonkey 可能提示授权访问 api.deepseek.com。
5. 点击“开始连播”。默认选择 2×、静音自动播放和后台兼容。首次使用先观察一个视频、一个 PPT 和一组章节习题，确认平台确实显示任务完成。需要停止时，点击“停止连播”。

播放配置仅保存在当前浏览器标签页的该课程会话中；DeepSeek API Key 和模型选项保存在 Tampermonkey 的本地脚本存储中，可通过“设置 DeepSeek Key”输入空值清除密钥。通过安装链接安装的脚本可由 Tampermonkey 按更新地址检查新版本。

## 章节习题

脚本识别章节内的单选、多选和判断题，从页面读取题干及选项；每题调用所选 DeepSeek 模型两次，只有答案一致且页面显示选项已选中时才提交整组习题。题干和选项会发送到 DeepSeek API，调用可能产生费用。[DeepSeek API 文档](https://api-docs.deepseek.com/api/create-chat-completion/)介绍了接口与模型参数。

图片内容无法读取、字体加密、题型不支持、两次答案不一致、API 出错或网页未确认选中时，脚本会停在当前习题任务点并保留连播状态，不会提交；手动完成该任务点后可继续后续任务。模型可能两次都答错，因此不能保证正确率；若提交后页面只显示分数或对错，脚本不会自动重做。习题提交后仍等待学习通的任务完成标记。

## 工作范围与限制

- PPT 按阅读区域可见高度约 80% 分步下滑；如果页面在底部继续加载新内容，会继续下滑。到底后仍未显示完成标记时，最多等待 60 秒，然后停止并提示。
- 若任务点明确提示不可倍速，脚本会直接用 1× 播放。否则先尝试面板所选倍速；播放器将倍速改回原速、在倍速下暂停或拒绝播放时，仅当前视频退回 1×，后续视频仍尝试所选倍速。任务是否完成以平台标记为准。
- 若课程只在服务端校验实际观看时长、网页没有可见的倍速限制，脚本无法提前识别。遇到这种情况，可在面板手动选 1×。
- 后台兼容只处理网页失焦和可见性回调。Chrome 可能节流或冻结最小化窗口中的页面，因此最小化后无法保证连续运行。
- 不支持的习题题型、验证码、跨域且不可访问的播放器，以及无法识别的任务点需要手动处理。脚本不会伪造任务完成标记，也不会自行发送进度请求。

## 本地开发与验证

    npm ci
    npm test
    npm run check

脚本本身没有运行依赖；jsdom 只用于模拟课程页面并测试任务切换、视频、PPT 与习题处理。项目采用 [MIT 许可证](LICENSE)。
